# 기관 상세 팝업 사용 기준

가장 중요한 내용을 먼저 부각해 사용자가 기관을 판단하도록 돕는 것을 최상위 목적으로 한다. 전국 요양과 전국 주간은 기관 주변 위치를 확인하는 기본 보기와 정보를 집중해서 읽는 확대 보기를 공유한다. 아래 검증표는 확인해야 할 기준이며 검증 완료 기록은 아니다.

## 판단에 필요한 핵심 요약

- 기관명·위치 다음에 공단 평가와 평가연도, 해당 유형에 맞는 정원·인력 정보를 요약한다. 요약만 보고도 근거와 자료의 시점을 구분할 수 있어야 한다.
- 확인되지 않은 값은 `미확인`으로 표시한다. 빈 값을 0명이나 미제공으로 바꾸지 않으며 요약에서 상세 근거를 이어서 확인할 수 있게 한다.
- 요양병원에는 공단 평가와 장기요양 정원·인력 요약을 적용하지 않는다. 복지용구에는 입소 정원·돌봄인력 지표를 표시하지 않는다. 각 유형의 출처와 이용 판단에 맞는 정보를 제공한다.
- 공단 평가를 후기 별점으로 표현하거나 기관 추천 순위로 해석하지 않는다. 정원으로 잔여 자리를 추정하거나 수집 인원을 상근인력으로 단정하지 않는다. 이용자의 장기요양등급과 예상 비용 조건도 임의로 추정하지 않는다.

## 화면과 정보 배치

- 모바일 세로 화면은 기본 `54dvh`, 사용자가 상세를 확대하면 `84dvh` 높이를 사용한다. 기본 보기에서는 지도와 상세를 함께 확인한다.
- 낮고 넓은 화면에서는 기존 목록 위 왼쪽에 상세 패널을 배치해 오른쪽 지도 공간을 남긴다. 상세 확대는 읽기 공간을 넓히고, 축소하면 기본 패널로 돌아간다.
- 닫기·크기 조절 바는 고정해 긴 내용에서도 접근할 수 있게 한다. 긴 기관명은 생략해 정보를 잃지 않도록 스크롤 영역에 포함한다.
- 기본정보·상세정보 탭은 스크롤 중에도 접근할 수 있도록 상단에 붙이고, 이전·다음 기관은 하단에 유지한다. 제목이나 버튼 때문에 본문이 가려지지 않아야 한다.

## 상태와 지도 유지

- 목록·마커·이전·다음으로 기관을 명시적으로 선택했을 때 선택 마커가 패널에 가려지면 보이는 지도 영역에 맞춘다. 내부 위치 보정으로 자동 재검색을 발생시키지 않는다.
- 상세 크기만 바꿀 때는 지도 중심·배율과 현재 탭·본문 스크롤·비교 상태를 유지한다.
- 이전·다음 기관 이동은 사용자가 선택한 상세 크기를 유지한다. 상세를 닫은 뒤 새로 열면 기본 크기로 복원한다.
- 상세를 닫으면 진입한 목록·지도 보기와 목록 스크롤을 복원하고, 지도 중심·배율은 기관 확인 위치를 유지한다.
- 사진 확대창이 열려 있으면 닫기·Esc는 사진 확대창부터 닫는다. 기관 상세의 탭·스크롤·지도 위치를 보존한다.

## 구현 검증 기록 · 2026-09-24

- 통합·주야간보호 지도에서 모바일 세로, 844×390 가로, 1440×900 데스크톱 팝업을 확인했다. 360px 화면에서 문서 가로 넘침이 없다.
- 확대·축소 시 지도 중심·배율과 스크롤 복귀를 확인했다. 다음 기관으로 이동하면 크기를 유지하면서 본문은 처음부터 표시한다.
- 사진 확대 후 Esc는 사진만 닫고 상세 크기와 사진 탭을 보존한다. 정보 탭은 방향키로 이동할 수 있다.
- 요양병원에는 공단 평가·장기요양 인력 지표가 표시되지 않는다. 미수집 인력과 실제 0명은 별도로 표시한다.
