# 검색 노출과 방문 유입 확인

<!-- SOFTM-SEARCH-OPERATIONS START 날짜:20260904 : 배포·색인 요청·검색 노출·실제 방문을 구분해 완료 판정이 앞서가지 않도록 운영 절차를 기록 -->

## 완료 기준

- 공개 도메인은 `https://homecare.designboard.net`이며 검색 등록을 막는 응답이나 메타가 없어야 한다.
- 구글과 네이버에서 `돌봄한눈`으로 검색했을 때 실제 사이트 링크를 찾을 수 있어야 한다. 날짜·검색어·확인 범위를 함께 남긴다.
- 두 검색 관리 도구의 노출수·클릭수 보고서에서 검색 유입을 확인한다. 조회 기간과 데이터 갱신일을 함께 확인하며 데이터 없음과 0건을 구분한다.
- 사이트 주소를 직접 열거나 운영자가 테스트하는 것만으로 방문객 유입 목표를 완료 처리하지 않는다. 검색결과를 반복 클릭해 유입 수치를 만들지 않는다.
- `site:` 조회는 보조 진단이며 브랜드 검색 노출이나 사이트 전체의 색인 수를 보장하지 않는다.

## 배포와 점검

1. 무관한 수집 데이터와 기존 스테이징을 제외하고 검색 관련 변경만 커밋한다. 원격 푸시는 사용자가 승인한 범위에서 수행한다.
2. GitHub Pages 배포 완료 SHA와 실제 HTTP 응답을 확인한다. 로컬 파일 변경만으로 운영 반영 완료라고 말하지 않는다.
3. `npm run check`에는 검색 검사기의 단위 테스트도 포함한다. 별도로 `npm run check:search`를 실행하면 실제 공개 사이트를 읽으며 외부 상태를 바꾸지 않는다. <!-- SOFTM-SEARCH-READINESS 날짜:20260904 : 검사기 자체의 오류와 운영 사이트 오류를 별도로 검증하도록 명령을 구분 -->
4. HTTP 검사 성공은 검색 준비 조건만 확인한다. Search Console URL 검사·네이버 URL 검사·실제 검색결과·성과 보고서를 별도로 확인한다.
5. 기본 검색 대표는 루트, 단일 `sitemap.xml`의 9개 유형별 페이지와 `about.html` 서비스 소개다. 지도 HTML의 `index,follow`를 유지한다. 현재 지도 canonical은 유형별 대표 페이지를 가리키므로 지도 주소 자체의 개별 색인은 보장하지 않는다. <!-- SOFTM-BRAND-IDENTITY 날짜:20260904 : 서비스 배경과 자료 출처를 공개한 문서까지 검색 점검 범위에 포함 -->
6. 배포 후 바뀐 홈페이지와 새 대표 페이지에 필요한 재수집·색인 요청을 한 번씩 제출하고 결과를 기록한다. 이미 접수한 같은 주소를 매일 반복 제출하지 않는다.
7. 수집과 보고서 반영을 기다리는 동안 하루 두 번 확인한다. 변화가 없으면 반복 알리지 않고 최초 노출·검색 클릭·오류·로그인 필요 등 의미 있는 변화가 생겼을 때 알린다.

## 추가 원칙

<!-- SOFTM-SEO-REGIONAL START 날짜:20260904 : 지역 검색 개선의 구현 완료와 실제 검색 유입을 구분하고 재생성 절차를 고정 -->
- 주력 검색어는 지역명과 `주간보호센터`, `요양원`, `방문요양센터`의 조합이다. 우선순위는 서비스 기능·검색 의도 기준이며 검색량 순위로 주장하지 않는다.
- `npm run build`는 수집 JSON으로 `data/care` 지도 검색 인덱스를 먼저 만들고 같은 자료로 지역별 전체 목록, 시도별 집계·링크, 유형 안내의 지역 링크와 단일 `sitemap.xml`을 생성한다. `npm run check`는 원본과 목록의 일치·한글 주소 링크·공단 평가연도·검색 설정을 검사한다.
- 지역 목록에는 지역별 실제 기관명·주소·평가연도를 표시하고 미확인을 낮은 등급으로 취급하지 않는다. 방문요양 소재지와 실제 방문 가능 지역을 구분하고, 입소시설 정원과 동일한 의미를 부여하지 않는다.
- 홈페이지 → 유형 안내 → 시도 → 시군구 목록 → 지역 필터가 적용된 지도 경로를 유지한다. 지역 URL은 자기 자신을 canonical로 사용한다. 지도 도구의 기존 유형별 canonical과 `index,follow`는 유지한다.
- 지역 페이지의 정적 탐색 계층은 일반 링크로 유지하고, 지역·기관명이 붙은 지도 필터 링크에는 `rel="nofollow"`를 일관되게 둔다. 지도 사용과 공유 주소는 유지하면서 수만 개의 필터 조합보다 사이트맵의 정적 지역 페이지가 먼저 수집되도록 한다. <!-- SOFTM-SEO-CRAWL 날짜:20260907 : 지도 필터 URL의 크롤 확장으로 핵심 지역 페이지 발견이 늦어지는 일을 방지 -->
- 지역 기관 수는 공단 수집목록의 기관기호 기준으로 안내한다. 같은 명칭·주소가 복수 기관기호로 수집되면 임의 병합하지 않고 해당 카드에 기관기호·지정일을 표시한다. <!-- SOFTM-SEO-DATA-DUPLICATE 날짜:20260907 : 재지정 가능 자료를 다른 물리 시설 수로 오해하지 않도록 수치와 구분 기준을 공개 -->
- 사이트맵의 지역 URL은 기존 루트 파일에 포함한다. 별도 사이트맵을 제출하거나 날짜만 매일 바꾸지 않는다. 새 내용이 배포된 후 Google·네이버에 기존 사이트맵을 한 번 다시 제출하고 주요 새 지역 URL의 수집을 요청한다.
- 배포 검사는 새 지역 페이지의 HTTP·본문까지 확인한다. 실제 검색 노출 및 클릭은 관리 도구의 조회 기간·갱신일을 명시해 확인하며 순위 상승을 보장하지 않는다.

- 유입 증빙과 사용자 계정 화면의 비공개 수치는 공개 저장소에 저장하지 않고 이 작업의 대화 또는 자동 확인 기록으로 남긴다.
- 브랜드는 HTML 제목, 보이는 대표 제목, `og:site_name`, 홈페이지 `WebSite` 이름에 일관되게 사용한다.
- 네이버 URL 검사에서 홈페이지 설명문은 `돌봄한눈`으로 시작하고 80자 이내로 유지한다. 이 검사는 검색 문서의 브랜드·주제를 명확히 전달하기 위한 준비 조건이며, 일반 `돌봄한눈` 검색의 순위 보장으로 해석하지 않는다. <!-- SOFTM-SEARCH-NAVER 날짜:20260910 : 색인 완료와 중의적인 브랜드 검색 순위를 구분하면서 네이버 진단 경고의 재발을 방지 -->
- 홈페이지 유형별 기관 수는 각 `data-category` 카드 안의 `data-count`만 갱신하고 `data/care/manifest.json`과 대조한다. 전국 요양원 대표 검색 의도는 `nursing-home-map.html` 한 페이지에 집중하고 같은 의도의 새 페이지를 만들지 않는다. <!-- SOFTM-SEO-FACILITY 날짜:20260907 : 잘못된 기관 수와 대표 페이지 경쟁으로 검색 신뢰가 분산되지 않도록 기준 고정 -->
- 요양원 대표 페이지의 기관 수는 title·description·공유 메타·구조화 데이터·본문에서 매니페스트와 함께 갱신한다. 중요한 검색 문서 수정일은 `dcterms.modified`로 선언하고 단일 사이트맵의 `lastmod`와 일치시킨다. <!-- SOFTM-SEO-LASTMOD 날짜:20260907 : 다음 수집 때 검색 제목과 본문 수치가 갈라지거나 실제 수정일 신호가 누락되지 않도록 유지 -->
- 홈페이지와 `about.html`은 돌봄한눈의 독립 정보 서비스 성격, 정부·공단·심평원 공식 서비스와의 구분, 자료 출처·제공 범위·시차를 방문자가 읽을 수 있게 설명한다. 운영자명·상호·연락처는 사용자가 공개를 확인한 정보만 쓴다. 소개·메타 보완만으로 검색 순위나 AI 요약 오류가 해결됐다고 판단하지 않는다. <!-- SOFTM-BRAND-IDENTITY 날짜:20260904 : 검색어 혼동을 확정 원인으로 단정하거나 확인되지 않은 운영 정보를 꾸미지 않도록 기준 고정 -->
- 검색 방문이 늘지 않으면 실제 검색어·랜딩 페이지 성과를 근거로 방문자에게 필요한 내용을 보완한다. 복제 페이지, 숨긴 키워드, 허위 후기, 자동 클릭을 만들지 않는다.
- 사이트 소유권 확인 파일은 유지한다. 새 유료 광고·분석 서비스·외부 게시물은 별도 승인 없이 시작하지 않는다.

## 네이버 갱신 통지

<!-- SOFTM-INDEXNOW START 날짜:20260907 : 누락된 favicon과 오래된 robots 판정을 실제 배포 후 안전하게 다시 수집시키는 절차를 고정 -->

- 네이버 사이트 진단에서 2026-09-05 기준 14개 페이지가 색인됐고, 접근 불가 1건은 `/favicon.ico`, `meta robots` 제외 1건은 2026-09-04에 수집한 `nationwide-care-services-map.html?type=nursing-hospital`의 이전 상태였다. 현재 지도는 `index,follow`이므로 과거 진단만 보고 다시 `noindex`를 넣지 않는다.
- 루트의 `favicon.ico`·`favicon.svg`·`apple-touch-icon.png`·`site-icon-512.png`를 함께 유지한다. 특히 `/favicon.ico`는 네이버 검색로봇이 직접 요청하므로 삭제하지 않는다.
- 새 페이지를 배포하거나 기존 페이지 내용을 실제로 바꾼 뒤에만 IndexNow로 해당 URL을 통지한다. 키 파일이 공개 사이트에서 확인되지 않으면 스크립트가 제출을 중단한다.
- 실행 예시: `npm run notify:indexnow -- --url / --url /about.html`. 기존 사이트맵 827개를 매번 일괄 제출하거나 같은 URL을 반복 제출하지 않는다.
- IndexNow 응답 성공은 갱신 신호의 접수일 뿐 색인·브랜드 검색 노출 완료가 아니다. 일반 검색 결과와 노출·클릭 보고서를 계속 별도로 확인한다.
