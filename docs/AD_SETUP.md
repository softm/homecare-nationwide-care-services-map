## 예상 비용 배너 운영

- `care-cost-ads.js`는 사용자가 하단 200px 근처에 접근했을 때 한 번만 광고를 요청합니다. 계산기 값을 바꾸거나 다시 계산해도 광고를 재생성하지 않습니다.
- 800px 이상은 728×90, 그 미만은 320×100을 선택하고 실제 광고 공간에 들어갈 때만 요청합니다. 광고를 축소하거나 자르지 않습니다. 화면 회전·폭 부족은 제휴 안내로 전환하고 페이지를 다시 열 때 맞는 단위를 선택합니다.
- 빈 ID·잘못된 규격·스크립트 오류·NOAD·10초 미로딩은 제휴 안내를 제공합니다. `mode: 'direct'`는 안내만 표시하고 `mode: 'off'` 또는 `enabled: false`는 영역을 숨깁니다.
- `node --test scripts/care-cost-ads.test.mjs`로 요청 시점·규격·실패 복귀·화면 전환을 검사합니다. 문의 전송 성공·실패는 브라우저에서 응답을 모의해 확인하고 실제 접수 시험은 요청받았을 때만 실행합니다.

## 2단계 기관 안내 상세

9개 기관 유형은 `인덱스 → 유형 안내 → 지도` 순서로 이동합니다. 주야간보호도 `daycare-map.html` 안내를 거쳐 다른 유형과 같은 `index.html?type=daycare` 지도를 엽니다. <!-- SOFTM-DAYCARE-UNIFIED 날짜:20260904 : 광고 안내의 이동 설명을 통합 지도 진입과 일치 -->

광고는 각 안내의 **제목·지도 찾기·자료 요약 아래, 이용 순서 위**에 한 개씩 배치합니다. `광고` 표시로 검색 버튼과 구분하며 화면을 덮거나 고정하지 않습니다.

### 유형 안내용 카카오 AdFit 광고

위에 기록한 안내용 **배너 광고단위 2개**를 9개 안내 페이지에서 공용으로 사용합니다. 별도로 다시 발급할 필요가 없습니다.

| 구분 | 승인 광고단위명 | 크기 |
|---|---|---|
| PC 안내 배너 | 돌봄한눈_2단계안내_PC | 728 × 90 |
| 모바일 안내 배너 | 돌봄한눈_2단계안내_모바일 | 320 × 100 |

카카오 AdFit의 웹 배너 지원 크기와 설치 예시는 [공식 Web 가이드](https://adfit.github.io/wiki/web-guide/)에서 확인할 수 있습니다.

단위를 재발급할 때는 새 **`data-ad-unit="DAN-…"` 값**을 PC·모바일로 구분해 교체하고 이 문서와 HTML의 설정 파일 버전을 함께 갱신합니다. 인덱스·지도 광고 ID는 재사용하지 않습니다.

### 유형 안내 연결과 표시

- 설정 파일은 루트의 `category-landing-ad-config.js`입니다. `kakao.desktop.unit`과 `kakao.mobile.unit`에 발급된 값을 각각 입력하고, 크기는 발급된 728×90·320×100과 일치시킵니다.
- `enabled: true`, `mode: 'hybrid'`로 승인된 광고를 요청합니다. 추후 ID를 비우면 `돌봄 서비스를 알려보세요 / 광고·제휴 안내` 카드를 표시합니다.
- `mode: 'direct'`는 제휴 안내만 표시하고, `mode: 'off'` 또는 `enabled: false`는 이 안내 광고 영역을 숨깁니다.
- 광고 요청 실패·NO-AD·미로딩에는 같은 위치의 제휴 카드로 돌아갑니다. 제휴 문의는 기존 `partner-inquiry.js` 오버레이를 사용하며 사용자 제출 때만 Web3Forms로 전송합니다.
- 800px 이상 화면은 PC 단위, 그보다 좁으면 모바일 단위를 선택합니다. 320px 화면에서도 광고 자체를 축소하거나 잘라 표시하지 않습니다. 화면 회전으로 규격이 바뀌면 중복 광고 요청 없이 제휴 안내로 전환하고 다음 페이지 로드에서 맞는 광고를 선택합니다.
- 문의에는 `data-care-category`의 실제 유형이 포함됩니다. 안내 페이지의 방문요양 문의가 주야간보호로 잘못 분류되지 않도록 유지합니다.

### 연결 후 확인

`npm run check` 후 PC·모바일에서 신규 단위 ID와 크기, 실제 광고 노출을 확인합니다. 광고 없음·차단 상황의 제휴 카드, 문의창 열기·닫기, 지도 버튼의 목적지도 확인합니다. 실제 접수 시험을 요청받은 경우에만 문의를 전송합니다.

## B2B 상품과 직접 광고

`advertise.html`에서 소개 페이지 제작(1회 110,000원 제안)과 예상 비용·서비스 소개 하단의 30일 홍보 카드(55,000원 제안)를 안내합니다. 총 결제금액 기준 제안이며 계약 전 확정합니다. 지도와 기존 AdFit 슬롯은 이 상품의 판매 지면이 아닙니다.

`sponsor-config.js`의 기본 `campaign: null`은 미계약 상태입니다. 실제 계약·결제·소재 승인 후에만 단일 광고주의 기간과 HTTPS 연결 주소를 설정합니다. 광고 카드에는 `광고`와 광고주명을 표시하며 검색순위·공단 평가와 분리합니다. 기간 밖에는 숨기고 열린 페이지는 1분 주기 및 화면 복귀 때 갱신합니다.

상품 선택·예산은 기존 Web3Forms 문의 메일에 포함합니다. 구체적인 운영 방법과 수익성 한계는 [B2B 수익모델 보고서](REVENUE_MODEL_REPORT.md)를 따릅니다.
