# 월 예상 장기요양 비용

<!-- SOFTM-CARE-COST-POLICY START 날짜:20260904 : 공식 수가 갱신과 화면 재사용 시 계산 범위·개인정보·기관자료의 경계를 유지 -->

`care-cost.html`과 두 지도의 기관 상세가 `care-cost-rates.js`, `care-cost-engine.js`, `care-cost-ui.js`, `care-cost.css`를 공유한다. 홈과 시설·주야간보호·방문요양 안내에서 진입한다. 장기요양등급을 기본 선택하지 않으며, 사용자가 누른 3등급 예시는 결과에 계속 표시한다. 장애 정도를 장기요양등급으로 환산하지 않는다.

## 공식 근거와 갱신

- 보건복지부 고시 제2025-247호, 2026-01-01 시행. 확인일 2026-09-04.
- [공단 고시](https://www.nhis.or.kr/lm/lmxsrv/law/lawFullContent.do?SEQ=1637&SEQ_HISTORY=594054), [국가법령정보센터 동일 고시](https://law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000271110&chrClsCd=010201).
- 제13조 월 한도·주야간 추가한도, 제18조 방문요양, 제31조 주야간보호, 제44조 시설 수가. 원문 표 이미지는 `source-data/care-cost/2026/`에 보관한다.
- [보건복지부 본인부담 안내](https://www.mohw.go.kr/menu.es?mid=a10712030100): 재가 15%, 시설 20%; 40% 감경은 각각 9%·12%, 60% 감경은 6%·8%, 면제는 급여 본인부담 0%다.
- 다음 연도에는 원문·수가표·적용일·확인일·독립 예제 검사를 함께 갱신한다. 기관 검색 인덱스나 상세 JSON을 비용표 대신 수정하지 않는다.

## 계산 범위

일반적인 단일 서비스의 월 1~31일, 방문요양 1일 1회만 계산한다. 기본 이용량은 시설 30일, 주야간보호 8~10시간 22일, 방문요양 180분 22회다. 야간·휴일, 가족요양, 치매전담 수가, 복수 서비스는 별도 조건으로 안내하며 일반 산식에 섞지 않는다. 요양병원은 적용 대상이 아니다.

급여 본인부담 = 한도 내 급여액 × 본인부담률. 월 한도 초과는 감경·면제 여부와 무관하게 전액 본인부담이다. 여기에 사용자가 확인하고 선택한 비급여만 더한다. 예산 표시는 원 단위 반올림이며 실제 청구의 단수 처리·가감액까지 확정한 견적은 아니다.

일반 주야간보호는 월 15일 이상·하루 8시간 이상 이용하면 1~2등급 한도 10%, 3~5등급 20% 추가를 적용한다. 인지지원등급의 치매전담실 추가한도는 이 일반 계산에 적용하지 않는다. 가족요양·다른 서비스 병용이 없는 전제다.

3~5등급 시설 계산은 인정서의 시설급여 확인이 필요하다. 인지지원등급은 일반 방문요양·시설 계산을 제공하지 않는다. 5등급 방문요양은 120~180분, 인지자극활동 60분을 포함한 인지활동형 조건을 안내한다. 3~5등급의 180분 초과 방문은 일반 계산에서 제외한다.

시설 A04는 공동생활가정 수가를 사용한다. A01·A02·A03·A05는 노인요양시설의 제44조 요양보호사 배치별 두 수가 범위를 표시한다. 수집된 현재 인력·입소자 수로 실제 적용 수가를 추정하지 않는다. 치매전담 코드만 가진 기관에 일반 수가를 적용하지 않는다.

## 비급여와 보관

기관별 정적 상세의 `serviceDetails[선택한 급여코드].sections.nonCovered`만 읽는다. 기관의 전체 급여를 합친 최상위 `nonCovered`는 사용하지 않는다. 동일 종류·산출근거·금액은 중복 제거하고 최신 수정일을 남긴다. 금액 미공개는 0원으로 변환하지 않는다.

항목은 기본 미선택이며, 공개 금액의 단위와 월 횟수를 사용자가 확인해야 합산한다. 같은 종류의 여러 가격은 서로 다른 항목이라는 별도 확인 전에는 모두 소계에서 제외한다. 미공개·미선택 항목은 실제 납부액에 추가될 수 있음을 표시한다. 독립 페이지의 직접 입력 비급여는 월 전체 금액임을 확인해야 포함한다.

비교함은 `careCompare:v1:{type}`, 비용 조건은 `careCost:v1:{service}`, 비급여 선택은 기관·급여별 키로 현재 브라우저 세션에만 저장한다. 기존 지도 공유 주소에 이용자 등급·본인부담·비급여 선택을 넣지 않는다. 주야간보호 두 지도는 같은 비교함 키를 공유한다.

## 검증

`scripts/care-cost.test.mjs`는 공식 수가의 독립 산식, 시설 범위, 감경·면제, 한도 아래·경계·초과, 주야간 한도 추가, 등급 자격, 비급여 누락·중복·단위 차이를 검사한다. `npm run check`에 포함한다. UI 변경 후에는 두 지도와 독립 페이지에서 실제 입력·복귀·세션 유지와 좁은 화면을 확인한다.

2026-09-04 구현 검수: 빌드·전체 검사 통과. 홈·비용·두 지도 360·390·768·1440px 너비 확인, 360px에서 글자 200% 확대와 비교표 내부 스크롤·닫기 확인. 두 지도 지역 필터·비교함 유지·상세 비용 연결·전화·사진 확대/앞뒤 이동/Esc 복귀를 검수했다. 비교 정렬 후 다운로드한 두 엑셀 파일의 실제 기관명을 확인했다. 지도 이동 자동 검색과 선택한 두 기관의 방문 경로(4.8km·약 10분)를 확인했다. 공통 클릭 이벤트가 페이지 전체를 막던 결함, 연속 선택/직접 지도 이동 후 복귀 간섭, 복수 급여기관의 시설유형과 비급여 코드 불일치를 수정했다.
