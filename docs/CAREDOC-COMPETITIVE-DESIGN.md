# 케어닥 비교 기반 돌봄한눈 정보·UX/UI 방향

- 조사일: 2026-11-18
- 조사 범위: 케어닥 비로그인 공개 홈, 시설찾기, 시설 상세, 돌봄 서비스, 고객지원·FAQ
- 참고 URL: `https://www.caredoc.kr/`, `https://www.caredoc.kr/facility`, `https://www.caredoc.kr/services`, `https://www.caredoc.kr/support`, `https://www.caredoc.kr/support/faq`
- 원칙: 케어닥의 상표·문구·이미지·색상을 복제하지 않고 정보 구조와 의사결정 흐름만 비교한다.

## 1. 관찰한 경쟁 UX

케어닥 시설찾기는 데스크톱에서 왼쪽 필터와 가로형 결과 행을 사용한다. 한 행은 사진, 기관 기본정보·특징 태그, 월비용 예시·상세 CTA로 나뉜다. 상세에서는 사진 갤러리, 평가, 비용, 정원·이용 현황, 인력, 시설, 프로그램, 교통·주차 정보를 긴 탭형 문서로 제공한다.

장점은 사진과 문의 행동이 빠르고, 사용자가 익숙한 시설 중심 언어를 사용한다는 것이다. 반면 추천 순서의 근거, 빈자리의 확인 시점, 개인 조건에 따라 달라지는 월비용의 계산 근거를 목록에서 바로 검증하기는 어렵다. 일부 정보는 기관이 직접 확인해야 하는 현재 상태인데 공개 행정자료와 시각적으로 구분되지 않는다.

### 관찰한 시각 시스템

- 흰 배경과 옅은 회색 구분선 중심, 그림자는 매우 약함
- 약 1,200px 안팎의 중앙 콘텐츠와 고정 폭 필터 열
- 둥근 사진, 베이지 계열 특징 태그, 주황색 주요 CTA
- 한 결과를 사진 / 판단정보 / 비용·행동의 세 영역으로 구성

수치는 화면 캡처에 기반한 근사치이며 케어닥의 공식 디자인 토큰이 아니다.

## 2. 돌봄한눈의 경쟁 우위

돌봄한눈은 전국 공공데이터를 기반으로 지도 생활권 탐색, 기관 비교함, 평가 근거, 조건별 공식 수가 계산을 한 흐름에서 제공할 수 있다. 경쟁 방향은 “추천처럼 보이는 카드”가 아니라 다음 네 가지를 검증 가능하게 만드는 것이다.

1. 공개 근거: 공단·심평원 출처와 자료 기준일
2. 판단 요약: 평가등급·평가연도, 등록 정원, 확인된 인력
3. 현재성 구분: 공개자료로 확인된 사실과 기관 문의가 필요한 빈자리·근무·재고·입원 가능 상태
4. 개인화 비용: 고정 월비용 대신 장기요양등급, 본인부담 유형, 이용량, 확인된 비급여를 입력하는 공식 수가 계산

## 3. 적용한 목록 정보 구조

PC 신규 방문자는 목록형을 기본으로 사용한다. 기존에 카드형·간단형을 선택한 사용자의 세션 선호는 그대로 유지하며 모바일은 카드형으로 시작한다.

가로형 한 행의 구조는 다음과 같다.

- 왼쪽: 공단 공개 사진
- 가운데 상단: 순번, 기관명, 주소
- 가운데 판단 영역: 유형별 공단 평가, 등록 정원, 확인된 인력 또는 심평원 개설일
- 가운데 근거 영역: 서비스 유형, 데이터 제공기관, 자료 기준일, 기관 확인 필요 항목
- 오른쪽 행동 영역: 담기·담은 기관 보기, 전화, 상세·비용, 지도 표시

요양원·주야간보호·방문요양의 `상세·비용`은 기존 공식 수가 계산기로 이어진다. 지원하지 않는 유형에는 비용을 약속하지 않고 `상세정보`로 표시한다.

## 4. 데이터 표현 안전 기준

- 등록 정원을 빈자리 수로 표현하지 않는다.
- 공개자료에 없는 대기자·현재 이용 가능 여부·재고·입원 가능 여부를 추정하지 않는다.
- 평가 미확인을 낮은 평가로 취급하지 않는다.
- 서로 다른 평가연도를 같은 순위처럼 비교하지 않는다.
- 인력 누락을 0명으로 바꾸거나 “충분”으로 평가하지 않는다.
- 지정일을 설립연도나 운영경력으로 바꾸지 않는다.
- 사진을 현재 모습이라고 단정하지 않는다.
- 개인 등급·감경·이용량 없이 고정 월비용을 제시하지 않는다.

## 5. 반응형·접근성 기준

- PC 1,001px 이상에서만 가로 비교형을 신규 기본값으로 사용한다.
- 모바일은 기존 카드 흐름과 44px 이상의 조작 영역을 유지한다.
- 보기 전환은 기관 DOM, 광고, 초점, 검색·지도 상태를 재생성하지 않는다.
- 출처와 확인 필요 상태는 색상만이 아니라 텍스트 레이블로도 구분한다.
- 긴 기관명·주소와 글자 확대에서도 가운데 정보 영역이 줄바꿈되도록 한다.

## 6. 후속 개선 우선순위

1. 상세 상단에 `좋은 점 / 확인할 점 / 미확인` 판단 요약 고정
2. 비교함에 출처·평가연도 정합성 표시와 동일 조건 비교 안내 강화
3. 넓은 화면에서 시설 유형별 고급 필터를 별도 필터 열로 전환
4. 사진 촬영·수정 시점과 현재성 안내 강화
5. 비용 계산 결과에서 포함·미포함 비급여와 기관 확인 항목을 비교함으로 연결

필터 열은 검색·지도·모바일 고정 영역에 미치는 영향이 커서 이번 1차에서는 도입하지 않는다. 먼저 목록의 실제 의사결정 정보와 행 밀도를 검증한 뒤 별도 반응형 단계로 진행한다.
