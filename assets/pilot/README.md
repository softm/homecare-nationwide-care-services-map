# 시범운영 안내 QR

<!-- SOFTM-KEY 날짜:20261121 : 실제 사용 주소와 인쇄용 QR의 생성 근거 -->

각 PNG는 640×640px, 4모듈 여백, 오류 정정 M으로 생성했다. QR 생성은 로컬 `qrcode` 패키지로 수행했으며 외부 QR 생성 서비스로 주소를 전송하지 않았다.

- `qr-institution.png`: https://homecare.designboard.net/care-pilot.html?src=institution
- `qr-welfare.png`: https://homecare.designboard.net/care-pilot.html?src=welfare
- `qr-community.png`: https://homecare.designboard.net/care-pilot.html?src=community

공식 사이트에 해당 페이지와 API가 반영되고, 실제 참여 기관 확인이 끝난 뒤 인쇄·배포한다. 파일에 기관 가입 증빙이나 개인 정보는 포함하지 않는다. 채널 구분값은 광고나 제휴의 성립을 뜻하지 않는다.
