돌봄한눈 개인정보처리방침

운영자 softmnet은 돌봄한눈 웹사이트(homecare.designboard.net)와 Android 앱(net.softm.care.homecare)에서 처리하는 정보를 아래와 같이 안내합니다. Android 앱은 웹사이트를 WebView로 제공하므로 웹 콘텐츠의 지도·광고·외부 연결에도 이 안내가 적용됩니다.

회원가입 없이 정보를 찾을 수 있습니다. 현재 위치 사용은 선택이며, 허용하지 않아도 지역·검색어로 조회할 수 있습니다. 외부 지도·광고·문의 서비스로 전달되는 정보와 기기에 남는 정보는 아래 항목에서 구분해 안내합니다.
처리 정보외부 서비스보유·삭제이용자 권리문의

1. 처리하는 정보와 이용 목적

현재 위치와 검색·공유

현재 위치 기능은 브라우저 또는 Android의 위치 권한을 허용한 경우 위도·경도와 정확도 정보를 이용하여 주변 기관 조회, 지도 이동 및 거리 표시에 사용합니다. 주소 확인·지도 표시 과정에서 좌표가 지도 제공자에게 전달됩니다. 백그라운드 위치 추적 기능은 제공하지 않습니다.

지도 중심 좌표, 배율, 검색어·필터가 주소창과 지도 공유 URL에 포함될 수 있습니다. 공유 버튼을 사용하면 선택한 앱이나 상대방에게 해당 URL이 전달됩니다. 현재 위치가 지도 중심인 경우 위치를 유추할 수 있으므로 공유 전 주소를 확인하세요. 운영자가 위치 이력을 별도 회원 데이터베이스로 구축하는 기능은 없습니다.

접속·이용 정보

웹페이지, 지도, 광고 및 외부 자료를 요청할 때 IP 주소, 요청 URL, 접속 시각, 브라우저·기기 정보, 오류·보안 관련 정보가 호스팅 및 해당 서비스 제공자의 서버에서 처리될 수 있습니다. 서비스 제공, 보안, 장애 대응, 광고 제공·측정에 사용됩니다. 웹 주소에 검색 조건이 포함되면 요청 URL에도 반영될 수 있습니다.

제휴 문의

문의 양식에서 기관·업체명, 담당자명, 회신 이메일, 문의 내용을 필수로 받고, 연락처·희망 지역·상품·예산은 선택 입력합니다. 상담 경로를 확인하기 위한 페이지 경로, 기관 유형, 문의 위치 및 동의 여부도 함께 전송합니다. 보내기를 누르면 Web3Forms를 통해 운영자의 이메일로 전달되며 상담·회신 목적으로 처리합니다. 선택 항목을 입력하지 않아도 문의할 수 있고, 필수 정보 전송에 동의하지 않으면 양식 접수는 이용할 수 없습니다.

경로·주변 분석과 예상 비용

도로 경로를 요청하면 출발지·도착지·경유지 좌표와 경로 옵션이 Vercel에 호스팅된 길찾기 API를 거쳐 네이버클라우드 지도 API로 전달됩니다. 주변 분석에 입력한 주소는 좌표 변환을 위해 지도 제공자에게 전달됩니다. 예상 비용의 등급·감경·이용 조건과 맞춤 조건은 브라우저에서 계산·처리하며 세션 저장소에 남을 수 있습니다. 이를 운영자의 회원·환자 데이터베이스로 전송하는 기능은 없습니다.

음성검색

지원하는 웹 브라우저에서 음성검색을 직접 실행하고 마이크를 허용한 경우 브라우저의 음성인식 기능을 사용합니다. 브라우저 제공자의 서버로 음성이 전달될 수 있으며 해당 제공자의 방침이 적용됩니다. 운영자는 음성 녹음 파일을 별도로 저장하지 않습니다. Android 앱은 마이크 권한을 요청하지 않으며 환경에 따라 음성검색이 지원되지 않을 수 있습니다.

공개 기관정보

기관·센터의 이름, 주소, 전화번호, 프로그램 등은 공공데이터와 공개 자료를 바탕으로 제공합니다. 이는 이용자의 건강·진단 정보가 아닙니다. 이용자의 진료기록, 치매 진단 결과, 주민등록번호, 연락처 목록 및 통화기록을 수집하는 기능은 없습니다. 문의 시 본인 또는 다른 사람의 진료기록 등 민감정보를 보내지 마세요.

2. 외부 서비스와 정보 전달

기능 제공에 필요한 범위에서 아래 서비스를 사용합니다. 각 제공자의 처리·보관 방식은 연결된 정책에서도 확인할 수 있습니다.

  • GitHub Pages: 웹사이트와 공개 데이터 파일을 호스팅합니다. GitHub 개인정보처리방침
  • 네이버 지도·네이버클라우드: 지도 표시, 주소·좌표 변환과 외부 길찾기를 제공합니다. 지도 영역·좌표·주소 및 접속 정보가 처리될 수 있습니다. 네이버 개인정보처리방침
  • 카카오 AdFit: 웹 광고를 제공합니다. 광고 요청·노출·클릭 정보, IP 주소, 브라우저·기기 정보 및 쿠키 등 온라인 식별정보가 광고 제공·측정과 부정 이용 방지에 사용될 수 있습니다. 운영자가 GPS 좌표를 광고 요청 항목으로 직접 전달하는 기능은 없습니다. 카카오 개인정보 보호 안내
  • Web3Forms: 사용자가 제출한 제휴 문의를 이메일로 전달합니다. Web3Forms 개인정보처리방침
  • Vercel·네이버클라우드: 도로 경로 요청 좌표·옵션과 접속 정보를 처리합니다. Vercel 개인정보처리방침 · 네이버클라우드 개인정보처리방침
  • 외부 앱·사이트: 전화, 길찾기, 기관 홈페이지, 공유 또는 이메일을 선택하면 해당 서비스로 이동하며 이후 처리에는 해당 서비스의 방침이 적용됩니다. 전화 기능은 다이얼 화면을 열며 앱이 직접 통화하거나 통화기록을 읽지 않습니다.

GitHub·Vercel·Web3Forms 등 해외 사업자의 인프라를 사용하는 과정에서 접속 정보·경로 요청·제출한 문의 내용이 국외에서 처리될 수 있습니다. 처리 지역과 제공자 보유기간은 서비스·인프라 정책에 따라 달라집니다. 관련 문의는 아래 운영자 이메일로 접수할 수 있습니다.

운영자는 이용자 정보를 판매하지 않으며, 위 기능 제공·사용자 요청에 따른 전달 또는 법령상 의무 이외의 목적으로 임의 제공하지 않습니다. Android 앱에는 광고 ID를 읽는 네이티브 광고 SDK를 포함하지 않습니다. 이는 웹 광고의 쿠키·접속 정보 처리와는 구분됩니다.

3. 저장 위치와 보유·파기

  • 기기 내 정보: 기관 비교함, 맞춤 조건, 비용 계산 조건, 검색·정렬·목록 표시 방식, 최근 지역, 광고 접힘 상태 및 주소·기관 좌표 캐시가 이용 환경에 남을 수 있습니다. 세션 저장소는 보통 해당 탭·세션 종료 시, 로컬 저장소와 쿠키·캐시는 사이트 데이터 삭제 또는 앱 데이터 삭제 시 제거됩니다. 일부 값은 기능별 만료나 덮어쓰기에 따라 먼저 없어질 수 있습니다.
  • 문의 이메일: 상담·회신과 후속 처리에 필요한 동안 보관하고 목적이 끝나거나 삭제 요청을 처리할 때 삭제합니다. 계약·거래·분쟁 또는 법령에 따라 보존할 필요가 있는 기록은 필요한 범위와 기간 동안 분리하여 보관합니다.
  • 외부 서비스 기록: 호스팅·지도·광고·이메일 제공자의 로그와 백업은 해당 제공자의 보존 정책을 따릅니다. 브라우저 기록이나 외부 제공자에게 이미 전달된 정보는 앱 삭제만으로 함께 삭제되지 않습니다.

불필요한 운영자 보유 전자 정보는 복구·재사용되지 않도록 삭제하고, 출력물이 있다면 파쇄 등으로 파기합니다. 공개 정보의 정정·삭제 요청은 원본 제공기관의 자료 처리와 구분해 안내합니다.

4. 권한 철회와 이용자 권리

  • 위치: Android 설정의 앱 권한 또는 브라우저 사이트 설정에서 허용을 철회할 수 있습니다. 위치 없이 지역·기관명으로 검색할 수 있습니다.
  • 기기 저장정보: 브라우저의 해당 사이트 데이터·쿠키 삭제, Android 설정의 앱 저장공간 데이터 삭제 또는 앱 제거로 정리할 수 있습니다. 저장한 조건도 초기화될 수 있습니다.
  • 광고·쿠키: 브라우저의 쿠키 차단·삭제 설정과 카카오 개인정보 보호 안내의 광고 관련 설정을 이용할 수 있습니다. 일부 광고·지도 기능이 제한될 수 있습니다.
  • 열람·정정·삭제·처리정지: 운영자에게 이메일로 요청할 수 있습니다. 요청 처리에 필요한 최소한의 본인 확인 후 처리하며, 법령상 제한이 있는 경우 사유를 안내합니다. 서비스에 회원 계정이 없어 별도의 회원 탈퇴 절차는 없습니다.

미성년자와 법정대리인도 정보 처리 문의 및 권리 행사를 요청할 수 있습니다. 서비스는 보호자·돌봄 관계자 등 일반 이용자를 위한 기관 정보 안내이며 아동의 개인정보를 의도적으로 수집하는 서비스가 아닙니다.

5. 정보 보호 조치

사이트와 앱의 네트워크 연결에 HTTPS를 사용하고, Android 앱은 일반 HTTP 웹페이지를 내부에서 불러오지 않도록 제한합니다. 운영자 보유 정보의 접근은 업무에 필요한 범위로 관리하며 공개 소스·공개 기관 데이터에 문의 내용과 이용자의 비공개 정보를 게시하지 않습니다.
